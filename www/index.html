Google Drive Sync

Required for OAuth. Find it in your Google Cloud Console.
Disconnected
How to setup Google Drive Sync?
  1. Go to Google Cloud Console.
  2. Create a project, then go to **APIs & Services > Credentials**.
  3. Configure **OAuth Consent Screen** (User Type: External, Add Scope: `.../auth/drive.file`).
  4. Go to **Credentials > Create Credentials > OAuth Client ID**.
  5. Select **Web Application**. Add `http://localhost:8000` (or your app's origin) to **Authorized JavaScript Origins**.
  6. Copy the Client ID and paste it here.
